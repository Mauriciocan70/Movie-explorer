# Movie Explorer

Movie Explorer es una aplicación web desarrollada con React y Vite que permite buscar películas utilizando la API de The Movie Database (TMDB). Los usuarios pueden consultar información detallada de cada película, visualizar su calificación, conocer su género y acceder al tráiler oficial cuando está disponible.

## Características

- Buscar películas por título.
- Mostrar las películas populares al cargar la aplicación.
- Visualizar información detallada mediante una ventana modal.
- Ver el tráiler oficial en YouTube (cuando está disponible).
- Mostrar un mensaje cuando no existen resultados.
- Indicador de carga (Preloader) durante las solicitudes.
- Botón **Mostrar más** para cargar más resultados.
- Diseño completamente responsive.

## Tecnologías utilizadas

- React
- Vite
- React Router DOM
- JavaScript (ES6+)
- CSS3 (Metodología BEM)
- Fetch API
- TMDB API

## ▶️ Instalación

Clona el repositorio:

- bash

git clone <URL_DEL_REPOSITORIO>


- Instala las dependencias:

npm install

- Inicia el servidor de desarrollo:

npm run dev

- Para generar la versión de producción:

npm run build

- Para previsualizar la aplicación compilada:

npm run preview

## Funcionalidades

- Página de inicio con películas destacadas.
- Búsqueda de películas.
- Resultados dinámicos.
- Modal con información detallada.
- Tráiler oficial.
- Diseño adaptable a dispositivos móviles, tabletas y escritorio.
- Manejo de errores y estados de carga.
